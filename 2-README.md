# Demo Automio · Roscamat (Tecnospiro Machine Tool)

Demo de compres i muntatge preparada per Automio per a Tecnospiro Machine Tool (Roscamat / 3ARM).

Totes les dades que hi apareixen (comandes, proveïdors, dates, correus i xifres) són fictícies i només serveixen per veure la idea. La demo no està connectada a cap sistema real de l'empresa.

## Veure la demo

Obrir `index.html` en qualsevol navegador, o visitar:
